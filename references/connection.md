# 连接 Obsidian

本文件仅在用户主动配置、同步、查询历史或要求读取单词本练习时读取，普通词义解释不读此文件、不查配置、不做连接测试。

本技能本身不提供网络服务。日常先解释并在当前聊天暂存；正式同步/历史统计需要实际访问保存词库的电脑和文件。

## 电脑端

1. 配置 Obsidian 笔记库内的专用目录，避免修改无关资料。
2. 在已加载 skill 的聊天中，实际读写一份标明“连接测试，不计入词库”的笔记，再读回核对。
3. 若工具提示目录不在授权范围，按宿主机制请求或取得该目录权限；不要假装已保存，也不要把整个笔记库复制到共享目录。

## 手机端：连接计算机

在手机 ChatGPT 的 Codex/Remote 入口，选择保存词库的电脑，并进入该电脑上的相关项目聊天。电脑需在线、保持运行；账号与工作区应匹配。看到入口、配对完成和实际文件读写成功是不同的检查点。

若尚未配对，按桌面应用设置中的连接流程，由用户扫描二维码并完成账号验证；不要把配对码或凭据存入词库。普通云端聊天并不会仅凭知道本地路径而取得文件权限。

验收：手机明确请求更新测试笔记 → 电脑实际读回 → 手机新聊天读取同一结果。新版再测试连续两次查词不落盘，主动同步后同一词条有两条查询事件，重复同步不增计数；主动问次数才报告次数。未完成这些操作时明确区分旧连接已验证与新版行为尚未现场验证。

## 其他 agent

复制技能目录到目标 agent 支持的位置，设置它自己的 notebook_path，并提供目录读写能力。可使用本地文件工具，或已配置且验证通过的远程工具；不自动绑定某个不存在的 MCP 服务器。不能读写文件的聊天仍可解释和暂存，但不能完成正式同步或核实已保存的历史频率。

## 平台确认

“单词默认暂存”不代表立即写入。用户明确说同步才执行保存；平台仍要求文件写入审批时照常完成。频率查询只读，不能借查询执行同步或更新文件。
