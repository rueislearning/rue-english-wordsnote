# 单词本记录格式

一个用户专用目录存放 `开始使用.md`、实际词条与练习记录。只在第一次保存实际词条或练习时创建相应文件夹，避免空分类。使用普通 Markdown，无需额外 Obsidian 插件或数据库。

## 词条

本文件仅在主动同步、查询或整理词库时读取，普通查词不加载。

按当前义项放入 `词条/名词/`、`词条/动词/`、`词条/形容词/`、`词条/副词/`、`词条/其他/`；短语统一放 `词条/短语/`，不确定放 `词条/待分类/`。文件名可用 `put off（推迟）.md`，冲突时加短 ID；路径字符 `/`、`\`、`..` 不作为词条文件路径。以 `entry_id` 为稳定身份，分类移动不重建历史。

读取词库必须递归扫描词条目录，并兼容旧版平铺文件，不因子文件夹漏掉历史。统计只读 `词条/`，不扫描私人备份、模板和连接测试。显式要求迁移时先备份；只补词性、移动路径及修复受影响链接，不擅改释义、次数或用户内容。同词多词性按义项分记录，不能复制同一条询问来制造次数。

使用 assets/entry-template.md。属性：

- `entry_id`：首次创建生成的 UUID，后续不变。
- `expression`：主要英文表达，保留标准拼写。
- `sense_zh`：本次语境对应的义项，不抄整本词典。
- `kind`：`word` 或 `phrase`。
- `part_of_speech`：`noun`、`verb`、`adjective`、`adverb`、`other`、`phrase` 或 `unknown`，分别对应上述目录；本版本将短语统一归为 phrase，不强行拆为多个单词。
- `inquiry_count`：本词条不同查询 event_id 的数量。
- `first_asked_at`、`last_asked_at`：原查询时间，已知准确时间则用 ISO 8601 含时区，仅知道日期时允许 `YYYY-MM-DD`，完全未知用空字符串。绝不用同步时刻补造查询时刻。

属性可用 YAML 双引号字符串，写入值时正确转义；模板中的空字符串与 0 是未填状态，空白模板不计入词库。

每条查询事件的内容：

```markdown
### 查询事件 <event_id>
- 时间：<原查询时间或 YYYY-MM-DD；未知则注明未知>
- 方向：en-zh 或 zh-en
- 原话：<用户实际提出的问题，保留理解表达所需的最短语境>
- 本次解释：<对应语境下的意思或用法>
```

不要保存无关私人对话。直接问词以提问消息作为事件；整句确认以原查询消息作为事件，确认不是另一次询问。优先用宿主稳定消息 ID；没有时日常解释仅按聊天顺序给 pending_key，首次同步时才可用工具生成 UUID，并在当前聊天保留 pending_key→event_id 映射和成功状态；重试、再次同步和只读统计沿用映射，不用英文表达本身充当事件 ID。日期来自原查询消息或当时可见的会话日期，不为取日期在查词阶段调用工具。

同一查询经多次工具调用只有一条事件；用户下次又问同一句话是新的事件。计数从去重事件数核对，不盲目执行旧数加一。已有手工导入词条没有查询事件时次数可为 0，注明来源，不推断遗忘。

待同步内容只存在当前可见聊天中；不写临时文件或自动扫描别的聊天来持久化。已同步则保留身份映射并从待同步集合移除，不从可见上下文再次收集一遍。只同步用户确认范围；同步词条和同步练习分别保留实际成功/失败状态，失败项原身份不变。

同形多义：bank 的“银行”与“河岸”各一条，分别计数。中译英与英译中指向同一表达同一义项时合并，查询事件保留各自方向。

只把记录相关部分合并到已有文件；正文“我的补充”以及其他用户内容保留。写前读取当前内容，写后再次读取核对；发生并发更新时重读合并，不能仅凭旧缓存覆盖。

## 时段频率（只读）

默认过去一周按用户当地日期，起始为今天减 6 天，结束含今天；例如 2026-11-05 查询为 2026-10-30～2026-11-05。支持用户指定其他时段，并在回答中写清范围。

递归读取每个词条的查询事件，用事件原日期筛选，再与当前聊天可见且已确认的待同步查询合并。同一英文表达跨义项/词性汇总时按 event_id 去重；待同步使用身份映射去重。inquiry_count 是历史总数，不能直接当本周次数；last_asked_at 也不能代替逐事件筛选。

例：exhibition 历史总数 8，其中所选一周已同步 3 次，本聊天待同步 2 次，报告 5 次；同步后再问仍为 5，统计不能落盘或将映射中的成功事件再加一次。

有可用事件且每词最多 1 次：无重复；没有可用事件：无查询记录；未知日期/不可见历史：单独说明覆盖限制。只返回至少 2 次的重复词，除非用户要求全量。查询、同步动作本身均不算查词，不增加次数。

## 练习记录

放在 `练习/`，每次练习单独一个文件，使用 practice-template.md。目标词使用 Obsidian 真实存在的笔记链接；无法指向已存在文件时保留文字和 ID，不创建假链接。

记录练习 ID、时间、场景、任务、目标词 ID、提示条件、原话、点评和每词实际表现。只保留与学习相关的用户原话；重述附在同一练习记录中，不覆盖第一次表达。

状态：

| 状态 | 证据 |
| --- | --- |
| 英文目标词可见时使用成功 | 目标词在本轮可见，用户在语境中正确使用 |
| 需要进一步提示 | 用户明确求助，或在提示后才能完成；注明提示和结果 |
| 本次使用困难 | 用户明确想用却想不起，或实际误用；反馈后是否改善另记 |
| 未观察到使用 | 本轮未使用或证据不足；不计为不会 |

引用练习记录即可，不需要每次练习都在所有词条中复制整段结果；回顾重点词时读取相关练习。查询次数只由查询事件决定。
