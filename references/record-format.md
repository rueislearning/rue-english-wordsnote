# 单词本记录格式

一个用户专用目录存放 `开始使用.md`、实际词条与练习记录。只在第一次保存实际词条或练习时创建相应文件夹，避免空分类。使用普通 Markdown，无需额外 Obsidian 插件或数据库。

## 词条

放在 `词条/`，文件名可用 `put off（推迟）.md`，冲突时加短 ID；路径字符 `/`、`\`、`..` 不作为词条文件路径。以 `entry_id` 为稳定身份，表达改名不重建历史。

使用 assets/entry-template.md。属性：

- `entry_id`：首次创建生成的 UUID，后续不变。
- `expression`：主要英文表达，保留标准拼写。
- `sense_zh`：本次语境对应的义项，不抄整本词典。
- `kind`：`word` 或 `phrase`。
- `inquiry_count`：本词条不同查询 event_id 的数量。
- `first_asked_at`、`last_asked_at`：真实事件时间，ISO 8601 含时区；旧数据不知时间时保留未知，不能补造。

属性可用 YAML 双引号字符串，写入值时正确转义；模板中的空字符串与 0 是未填状态，空白模板不计入词库。

每条查询事件的内容：

```markdown
### 查询事件 <event_id>
- 时间：<真实查询时间>
- 方向：en-zh 或 zh-en
- 原话：<用户实际提出的问题，保留理解表达所需的最短语境>
- 本次解释：<对应语境下的意思或用法>
```

不要保存无关私人对话。直接问词以提问消息作为事件；整句确认以原查询消息作为事件，确认不是另一次询问。优先用宿主稳定的消息 ID；无法获取时在首次处理消息时生成 UUID 并沿用至保存成功，不用英文表达本身充当事件 ID。

同一查询经多次工具调用只有一条事件；用户下次又问同一句话是新的事件。计数从去重事件数核对，不盲目执行旧数加一。已有手工导入词条没有查询事件时次数可为 0，注明来源，不推断遗忘。

同形多义：bank 的“银行”与“河岸”各一条，分别计数。中译英与英译中指向同一表达同一义项时合并，查询事件保留各自方向。

只把记录相关部分合并到已有文件；正文“我的补充”以及其他用户内容保留。写前读取当前内容，写后再次读取核对；发生并发更新时重读合并，不能仅凭旧缓存覆盖。

## 练习记录

放在 `练习/`，每次练习单独一个文件，使用 practice-template.md。目标词使用 Obsidian 真实存在的笔记链接；无法指向已存在文件时保留文字和 ID，不创建假链接。

记录练习 ID、时间、场景、任务、目标词 ID、提示条件、原话、点评和每词实际表现。只保留与学习相关的用户原话；重述附在同一练习记录中，不覆盖第一次表达。

状态：

| 状态 | 证据 |
| --- | --- |
| 英文目标词可见时使用成功 | 目标词在本轮可见，用户在语境中正确使用 |
| 需要进一步提示 | 用户明确求助，或在提示后才能完成；注明提示和结果 |
| 本次使用困难 | 用户明确想用却想不起，或实际误用；反馈后是否改善另记 |
| 未观察到使用 | 本轮未使用或证据不足；不计为不会 |

引用练习记录即可，不需要每次练习都在所有词条中复制整段结果；回顾重点词时读取相关练习。查询次数只由查询事件决定。
